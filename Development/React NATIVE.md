## Expo
>[!info] [Expo](http://expo.io/) — это фреймворк и платформа для универсальных приложений React. Это набор инструментов и сервисов, созданных на основе React Native и нативных платформ, которые помогают вам быстро разрабатывать, создавать, развертывать и выполнять итерации для iOS, Android и веб-приложений с использованием одной и той же базы кода JavaScript/TypeScript.

https://docs.expo.dev/get-started/create-a-project/
Создаём проект с фреймворком Expo
```bash
npx create-expo-app@latest
```

Переходим в директорию с проектом и запускаем
```bash
npm start
```

Или же удаляем по максимуму бойлерплейт
```bash
npm run reset-project
```
